# Fitted-model boundary

The scientific model implementations are visible in Notebooks 03–05. This directory is a path placeholder, not a collection of pretrained models.

The primary local experiment contains 540 frozen objects: nine model variants × ten seeds × six monthly windows. Their matching input, feature, split, model and calibration contracts must be preserved together when reusing predictions.

Fitted objects and row-level prediction caches are not included in this public snapshot. Saved scientific tables and figures remain available without them. See [runtime prerequisites](../dataset/README.md); a fresh-clone “Run All” is not certified.

No external scientific Python scripts are supplied or required as notebook implementation files.
